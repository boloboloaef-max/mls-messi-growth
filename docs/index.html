The growth of U.S. soccer—and the Messi effect

Major League Soccer's recent evolution is written into its match scores. This project follows the league from its 2017 season through 2025, then looks closer at the arrival of Lionel Messi and what changed around Inter Miami.

Data in brief. The local file combines 2,505 MLS rows from an archived FiveThirtyEight SPI match file with 1,583 completed non-All-Star MLS scoreboard events from ESPN for 2023–2025. xG is not supplied in the later ESPN rows, so no post-2022 xG values are imputed. The analysis is descriptive, not causal.
