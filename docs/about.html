Data source

Observed match records

The observational dataset mls_matches.csv contains 4,088 MLS matches across 9 seasons (2017–2025), with 12,124 goals and 2,504 matches with complete paired expected-goals records. Scores extend through 2025; xG is present only where both source values were recorded, and no missing values are estimated. View the source data file.
