Match-level efficiency

Actual goals against expected goals

Each point is one team’s score and xG in one match. Points above the reference line finished above the recorded expectation; points below finished under it.

A match-level finishing margin is noisy: it is a descriptive difference, not a stable measure of individual finishing skill.

All figures are computed from the checked-in match-level CSV. Paired xG is available only where both values are present; missing xG is never imputed. Descriptive patterns are not causal estimates.
